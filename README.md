# 📊 Smart Sales Analytics

## 📌 Project Overview

Smart Sales Analytics is a Python-based data analytics project developed to analyze sales data and generate meaningful business insights.

The project uses **Pandas** for data analysis and **Matplotlib** for data visualization.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV Dataset
- Data Analysis
- Data Visualization

## 🔍 Key Features

- Sales data analysis
- Product-wise sales analysis
- Region-wise sales performance
- Category-wise performance analysis
- Top-selling product identification
- KPI Summary
- Data visualization using 6 charts
- Business insights generation

## 📊 Business Insights

- Laptop was identified as the top-selling product.
- South region generated the highest sales.
- Electronics was the highest-performing category.

## 📈 Visualizations

The project includes charts for analyzing:

- Product Performance
- Regional Sales
- Category Performance
- Sales Trends
- Quantity Analysis
- Overall Sales Performance

## ▶️ How to Run

1. Clone or download this repository.
2. Make sure Python is installed.
3. Install required libraries:

```bash
pip install pandas matplotlib
```

4. Keep `sales_analysis.py` and `sales_data_200.csv` in the same folder.
5. Run:

```bash
python sales_analysis.py
```

## 🎯 Project Objective

The main objective of this project is to transform raw sales data into useful information that can support better business decision-making.
